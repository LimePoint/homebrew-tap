# LimePoint tap

Homebrew formulae and scoop manifests for LimePoint products, regenerated
by each product's release train from its release checksums.

    brew tap limepoint/tap
    brew install limepoint/tap/opschain

    scoop bucket add limepoint https://github.com/LimePoint/homebrew-tap
    scoop install limepoint/opschain

How to install OpsChain, and how to verify a download:
https://docs.opschain.io/docs/getting-started/0-0-install-opschain
